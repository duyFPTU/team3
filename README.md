# Quản lý thư viện

Khung ban đầu để các thành viên clone về và phát triển trên nhánh riêng.

- `client/` — giao diện.
- `server/` — backend.
- `database/` — nơi nhóm sẽ thêm thiết kế cơ sở dữ liệu.

Xem [đề bài gốc](MOCK_PROJECT_REQUIREMENTS.md) trước khi nhận phần việc.

## Chạy giao diện React

Từ thư mục gốc của repo, chạy:

```sh
cd client
npm ci
npm run dev
```

Mở địa chỉ Vite hiển thị trong terminal. Component đầu tiên nằm tại `client/src/App.jsx`.
